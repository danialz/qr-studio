# Contributing to QR Studio

Thanks for making the web more useful.

1. Open an issue describing your proposed change before implementing larger features.
2. Create a focused branch; avoid unrelated cosmetic or dependency changes.
3. Run `npm test` and `npm run build`. Add tests for content encoding and security-sensitive flows.
4. Open a pull request explaining the UX impact, test results, and screenshots if the interface changed.

Please avoid sending user data to external APIs. Any new network-facing capability must be discussed and documented explicitly. Be respectful and constructive in reviews.
